类似 Claude Code 终端的紧凑运行界面,作为可选模式:上方是模型步骤流,中间是 Todo List,最下方是运行动画 + 当前步骤类型。点右侧按钮或自动播放来查看各状态。

    布局

    1

    步骤流:模型每一步(思考 / 读文件 / 编辑 / 命令)一行,新步骤从底部推入;越旧越淡,超出自动折叠为「N 个更早的步骤」。

    2

    Todo List:取自 agent 的计划,圆角卡片;待办为虚线圈,进行中转圈,完成实心并划线。点右上角计数可折叠到只剩当前项。无计划时整块隐藏。

    3

    状态条:左侧运行动画,右侧当前步骤类型(Thinking / Running Command…)与用时,▸ 展开详情;最右是 token 和中断。

    动画与步骤类型
