交互规则

  • 没有边栏:卡片直接铺在对话右侧,无背景、无分割线、无标题栏;卡片之间的空隙点击穿透到对话。对话区自动让出右侧宽度,卡片全部隐藏后恢复整宽。
  • 把手在右上角:鼠标移到卡片上,右上角淡入「隐藏」和六点把手(盖住折叠摘要)。触屏设备常显。
  • 排序:拖动把手。被拖卡片抬起并跟手,其余卡片以 FLIP 动画让位;靠近上下边缘自动滚动。
  • 键盘排序:聚焦把手,空格 拿起 → ↑↓ 移动 → 空格 放下,Esc 取消,并用 aria-live 播报位置。
  • 折叠:点标题行折叠;折叠后右侧留一行摘要(分支、87%、+2,571 −177…),不展开也能扫一眼。
  • 隐藏与找回:有隐藏卡片时,栈底出现「添加卡片」,点开可逐张找回或恢复默认布局。
  • 模式切换:卡片模式与经典标签页模式只在 设置 → 外观 切换,面板上不放开关。
  • 尊重 prefers-reduced-motion:动画时长降为 0。
