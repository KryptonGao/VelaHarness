# 浏览器元素批注需求文档

状态：P0（EA-01–EA-09）已实现；P1、P2 尚未开始。  
日期：2026-10-26。  
范围：Vela 桌面端右侧内置浏览器面板中，对页面元素写批注，并把批注作为下一轮对话内容的一部分发送给 Agent。  
产品名称：元素批注；英文：Element Annotations。

## 1. 产品目标

开发者在内置浏览器里预览本地或线上页面时，常常要对某个具体元素提意见（“这个按钮太小”“这段文字颜色对比不够”）。现在只能手写描述或自己截图，Agent 很难定位到对应元素和代码。

元素批注让用户在页面上点选元素、写一句话，批注与对话里“选中文字后回复”是同一种东西：它是下一轮用户消息的一部分，随消息一起发给 Agent。

主要流程：**进入批注模式 → 点选元素 → 写批注 → 继续批注其他元素 → 在输入框补充说明（可选）→ 发送。**

## 2. 当前实现基线

| 能力 | 当前实现依据 | 与批注的关系 |
| --- | --- | --- |
| 浏览器面板 | `apps/desktop/src/renderer/components/browser/BrowserPanel.tsx`、`BrowserViewHost.tsx`；[浏览器](../browser.md) | 批注入口、元素高亮和编号标记在这里呈现；`<webview>` 常驻挂载，批注不能破坏其生命周期。 |
| 浏览器主进程 | `apps/desktop/src/main/browser-host.ts`、`browser-cdp.ts`；`packages/shared/src/browser.ts` 的 `BrowserUiCommand` | 元素拾取经主进程 CDP 完成，新增命令走同一套 IPC 校验。 |
| Agent 指针覆盖层 | `BrowserAgentPointer.tsx` | 先例：覆盖层由应用自己绘制，不在页面 DOM 中，也不进入 Agent 截图。批注标记沿用这一做法。 |
| 选中文字回复 | `components/selection-actions.ts` 的 `ReplyDraft`、`ReplyCard`、`replyMessage`、`hasReplyText`；`Composer.tsx` 的 `replies`；`ChatView.tsx` 持有 `replies` 状态 | 批注复用这套卡片、排序、移除、清空和发送语义。 |
| 输入框图片附件 | `FileAttachmentPayload`、`ImageAttachment`；`Composer.tsx` 的 `attachments` | 元素截图作为图片随消息发送。 |

页面是不受信任的远程内容：沙箱、上下文隔离、无 Vela preload、不暴露任意 CDP。因此**不得向页面注入脚本**，元素拾取、读取属性和截图都由主进程完成。

## 3. 范围与分期

| 级别 | 需求 ID | 交付范围 |
| --- | --- | --- |
| P0：首版 | `EA-01–EA-09` | 批注模式、元素拾取与高亮、批注内容、编号标记、与回复统一的卡片、消息组装与截图、批注生命周期、多语言、安全限制。 |
| P1：增强 | `EA-10–EA-13` | 框选区域与文字选段批注、前端框架元件名与源码位置、批注草稿跨重启保存、对话历史中把元素引用渲染为标签。 |
| P2：探索 | `EA-14–EA-15` | 暴露给 Agent 的批注读取工具、Agent 处理后标记批注为“已处理”。 |

不包含：多人协作批注、批注写回网页或数据库、非 HTTP(S) 页面批注、页面内手绘涂鸦。

## 4. 首版需求（P0）

### EA-01 批注模式

- 浏览器工具栏新增“批注”开关按钮；进入模式后按钮为选中态，`Esc` 或再次点击退出。
- 模式内鼠标移动高亮元素，点击选中并弹出批注输入，页面自身的点击、链接跳转、表单提交都不会触发。
- 模式只作用于当前标签页；切换标签页、切换对话或收起面板时自动退出模式，但已写的批注保留。
- 空白页（`UI_BROWSER_BLANK_URL`）、加载失败页上按钮禁用。
- Agent 正在操作该对话浏览器时（`operating`）按钮禁用，避免人和 Agent 争用输入。

### EA-02 元素拾取与高亮

- 由主进程通过现有 CDP 通道完成：命中测试取得元素，高亮由 Chromium 的 CDP Overlay 绘制，不改页面 DOM、样式或事件。
- 支持同源和跨域 iframe（OOPIF 用 CDP 子会话）、开放的 Shadow DOM。
- 点选结果允许用 `Alt` + 滚轮或上下方向键在父子层级间调整，默认取最内层可见元素。
- 隐藏元素、`pointer-events: none` 元素仍可通过层级调整选中其可见祖先，不报错。
- 页面在拾取过程中发生导航或元素被移除时，放弃本次拾取并提示，不留下半条批注。

### EA-03 批注内容

每条批注包含：

| 字段 | 说明 |
| --- | --- |
| 批注文字 | 用户输入，可为空；单条上限 2,000 字符。 |
| 页面 | URL（按 EA-09 脱敏）和标题。 |
| 元素描述 | 标签名、`id`、`class`、`role`、可访问名称、文字摘要（上限 120 字符）。 |
| 选择器 | 尽量稳定的 CSS 选择器，优先 `id`、`data-testid`、语义属性，退而求其次用层级路径；帧内元素带帧路径。 |
| 几何信息 | 元素在 CSS 视口内的位置与尺寸，以及视口大小。 |
| 关键样式 | 白名单计算样式：`color`、`background-color`、`font-size`、`font-weight`、`margin`、`padding`、`display`、`position`。 |
| 元素截图 | 元素裁切 PNG，长边不超过 1,200 px，带编号角标；超大元素只截可见部分。 |

字段总文字量按元素描述 + 选择器 + 样式合计限长（建议 1,500 字符），超出截断并标注。

### EA-04 页面上的编号标记

- 每条批注在页面上显示编号气泡和元素选框，由 Vela 渲染层覆盖在 `<webview>` 上方绘制，不进页面 DOM、不进 Agent 截图，也不拦截手动输入（批注模式外）。
- 页面滚动、缩放、面板拖动改变尺寸时，标记按元素最新位置跟随；元素被移出视口时隐藏标记。
- 元素在导航或重排后找不到时，批注标为“已失效”：卡片保留并显示提示，页面上不再画标记，仍可发送（此时只含文字和元素描述）。
- 尊重 `prefers-reduced-motion`。

### EA-05 与回复统一的卡片

批注是回复的另一种来源，不另起一套 UI：

- 把 `ReplyCard` 扩成带类型的结构：`kind: "text"`（现有选中文字）和 `kind: "element"`（元素批注）。两者出现在输入框上方同一排卡片中，按创建顺序排列。
- 元素卡片徽标显示“批注”（文字回复仍显示“回复”）；单卡可移除，也可整体清空；移除卡片时页面上对应标记一并消失。
- 卡片文字：写了批注就显示批注，否则显示元素简述，如 `button.primary「提交」`，规则同 `replyCardText`。
- 批注创建后光标回到输入框（同选中文字回复的行为），用户可继续补充。
- 点击元素卡片可在面板中定位并闪烁对应元素（面板被折叠时先展开）。

### EA-06 发送规则

- 沿用 `hasReplyText`：任一卡片有文字，输入框可留空直接发送；只有元素没有文字的批注，输入框必须有内容才能发送。
- 运行中按现有追加指令投递：`Enter` 排队，`⌘/Ctrl+Enter` 调整当前任务，批注卡片同样随这条指令发出。
- 发送失败（消息没有留下）时，卡片和附件原样放回，页面标记保留。
- 发送成功后卡片清空，页面标记一并清空（与文字回复语义一致）。

### EA-07 消息组装与截图

- 每条批注组成“元素引用块 + 批注文字”一组，与文字回复混排，顺序即卡片顺序，输入框里的补充文字放最后（扩展 `replyMessage`）。
- 元素引用块为 Markdown 引用，例如：

  ```
  > [页面批注 1] http://localhost:3000/settings（设置 - Vela）
  > <button.primary> “提交” · role=button · 选择器 form > button.primary
  > 位置 640×420，大小 96×32 · color=#fff · background-color=#2563eb · font-size=12px · 见图 1
  ```

  这些文本是**资料**而非指令；元素文字与属性按原样引用，引用块不使用围栏之外的标记。
- 元素截图作为图片附件随消息发送，引用块写“见图 N”。图片数量上限 4 张，超过的批注只发文字并注明“截图已省略”。
- 图片总大小受现有图片附件上限约束，并计入输入框附件上限；若与用户已添加的附件相加超限，优先保留用户自己添加的附件。
- 单条消息引用的批注数量上限 20 条，超出时禁止继续添加并提示先发送。

### EA-08 状态与生命周期

- 批注按对话保存，保存在对话级共享状态中。现在 `replies` 是 `ChatView` 的内部 state，而批注产生于浏览器面板，需要把卡片状态提升到按对话区分的共享 store，由浏览器面板和 `Composer` 共同读写。
- 批注属于所在浏览器标签页：关闭标签页，其批注一并移除；导航到别的页面时已有批注按 EA-04 标为“已失效”。
- 切换对话、打开设置、收起面板、切换标签页都不丢失批注；重启应用不恢复（P1 再做草稿保存）。
- 批注创建、编辑、删除是纯本地操作，不触发网络请求，也不进入 Agent 上下文，直到用户发送。

### EA-09 多语言、可访问性与安全

- 新增文案同时提供 zh-CN 和 en，并在 `packages/shared/src/i18n-messages/` 补齐 zh-TW、ja、ko。
- 批注按钮、卡片、输入弹层均为原生元素，具备名称和状态，可用键盘进入模式、切换层级、确认与取消。
- 页面无法检测或读取批注；元素拾取与高亮不向页面派发任何事件。
- 密码输入框（`type=password`）及带 `autocomplete` 为敏感类别的字段，值永不读取；其余输入框只取 `placeholder` 与标签，不取用户已填值。
- URL 引用保留 origin 与路径；查询串中的参数值默认保留，但命中常见令牌参数名（如 `token`、`key`、`secret`、`password`、`code`）时值替换为 `…`。
- 元素截图只从该元素区域生成；裁切区域内若包含密码框，则对该框区域打码。
- 新增的 `BrowserUiCommand` 仍需通过现有校验：本地主框架 IPC 发送者、guest 嵌入者、持久会话标识、窗口归属；不暴露任意 CDP，也不新增远程调试端口。

## 5. 增强与探索（P1/P2）

| 需求 ID | 内容 |
| --- | --- |
| `EA-10` | 框选区域批注、页面文字选段批注，与元素批注同卡片类型。 |
| `EA-11` | 识别 React、Vue 等框架的元件名与源码位置（如 dev 模式下的 `_debugSource`、`__vueParentComponent`），在引用块中给出文件与行号，让 Agent 直接定位代码。 |
| `EA-12` | 批注草稿按对话持久化，重启后恢复并尝试重新定位元素。 |
| `EA-13` | 对话历史中，把发送过的元素引用块渲染为小标签，而不是原样的引用文字。 |
| `EA-14` | 提供 Agent 工具读取当前对话的批注列表，用于长任务中重新核对。 |
| `EA-15` | Agent 修改后自动刷新页面，并把对应批注标为“已处理”。 |

## 6. 边界行为

| 情况 | 行为 |
| --- | --- |
| 批注过程中页面导航 | 已有批注标为“已失效”；正在输入的批注保留文字，元素信息保留，标记不再绘制。 |
| 点选元素在跨域 iframe 内 | 记录帧路径和元素信息；若无法取得样式或截图，只发文字与可得字段。 |
| 页面响应缓慢或截图失败 | 批注仍可创建，卡片提示“未能截图”，消息中不含图。 |
| 元素非常大（整页容器） | 截图只含可见部分，引用块标注“已裁切”。 |
| 同一元素重复批注 | 允许，作为不同编号的批注。 |
| 批注模式下页面弹出 `alert`、`beforeunload` 对话框 | 走现有浏览器对话框处理，批注输入保留。 |
| 对话正在运行时创建批注 | 允许；发送时按追加指令投递。 |
| 面板宽度很小 | 工具栏按钮折叠到溢出菜单，行为不变。 |

## 7. 验收与测试

- 用 `pnpm dev` 打开本地页面，进入批注模式，点选元素并写批注，输入框上方出现“批注”卡片；创建 3 条以上批注，滚动、缩放页面和拖动面板分隔条后，标记仍对位。
- 发送后，用户消息里包含按顺序排列的元素引用块和批注文字，Agent 收到截图；卡片和页面标记一并清空。
- 与文字回复混合使用时顺序正确；只有元素没有文字的批注需要输入框内容才能发送；运行中按排队、调整两种方式投递均正确。
- 密码框、令牌参数、含密码框的截图按 EA-09 处理；页面脚本无法观察到批注行为；批注覆盖层不出现在 Agent 截图和页面 DOM 中。
- `pnpm test`（含类型检查）、`pnpm build && pnpm test:smoke`、`pnpm test:ui` 通过；新增单元测试覆盖：消息组装与限长、卡片 `kind` 扩展与 `hasReplyText` 规则、URL 脱敏、新增 `BrowserUiCommand` 的 IPC 校验、元素失效判定。

## 8. 已确定的决定

| 问题 | 决定 |
| --- | --- |
| 送给 Agent 的形态 | 与“选中文字回复”同一套卡片；元素引用块 + 批注文字合并入消息，截图作为图片附件。 |
| 批注归属 | 按对话保存，同时属于所在标签页，关闭标签页即移除。 |
| 截图附件上限 | 每条消息 4 张。 |
| 发送后页面标记 | 与卡片一并清空。 |
| Agent 主动读取批注的工具 | 暂不做，列入 P2（`EA-14`）。 |
| 框架元件名与源码定位 | 列入 P1（`EA-11`），首版只做 DOM 与样式信息。 |
