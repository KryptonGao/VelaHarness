# 工作面板分屏（实验性）

> **实验性功能，默认关闭。** 在「设置 → 界面 → 工作面板分屏（实验性）」中开启，偏好保存为 `vela.workbenchSplit`。关闭时工作面板只有一个窗口，标签不能拖动，也没有「窗口操作」菜单；已有的分屏会合并回单窗口（标签按窗口顺序拼接，保留聚焦窗口当前显示的标签，不会关闭任何标签）。重新开启后从单窗口开始，不恢复之前的布局。

右侧工作面板可以同时显示最多四个窗口。主对话保持独立；界面不提供窗口数量切换器，也不显示布局名称。顶栏继续使用原有半透明玻璃，标签栏保持原来的 52px 高度、胶囊尺寸和留白。

## 使用

- 拖动标签到某个窗口页面内容的左、右、上、下边缘，在对应位置拆出窗口；拖动期间只显示强调色落点预览，松手后才改变布局。
- 拖动的是窗口自己的标签时，窗口中部没有可互换的对象，会取最近的一条边拆分，不留没有落点的死区。
- 拖到其他窗口的标签栏，把被拖动的页面收回到这一栏，并切换显示该标签。源窗口空了就自动收拢；源窗口仍有其他标签则保留。标签栏优先于边缘命中，只在栏上显示强调色示意，不触发分屏或页面互换。
- 拖到其他窗口的中间，与该窗口当前显示的标签原位互换，不改变窗口数量、位置和分隔比例。其他标签的顺序不变；若拖动的是源窗口的非当前标签，源窗口继续显示原来的页面。
- 三窗口既可以左右排列，也可以上排两个、下排一个，或上排一个、下排两个；排列由落点决定。
- 每个窗口独立切换标签；标签栏的 `+` 在对应窗口中新建标签。拖动标签到自己或其他窗口的标签栏时，出现蓝色插入线，松手后落在该位置，可以在窗口内重排标签；被拖动的标签会变淡。
- 每个窗口有最小尺寸（宽 240px、高 200px）。拆分后会让任何窗口低于这个尺寸时，不显示落点预览，松手或键盘拆分也不生效并提示“空间不足”；内部分隔线同样不能拖到低于该尺寸。窗口较窄（≤340px）时，「放大窗口」和「关闭窗口，保留标签」按钮收进「窗口操作」菜单。
- 分屏时没有焦点的窗口，选中标签的文字降一级，聚焦窗口一眼可辨；`+` 和 `Alt + 1`–`Alt + 4` 作用于聚焦窗口。
- 拖动内部的分隔线调整比例，双击恢复均分。聚焦分隔线后可用方向键微调，`Home` 恢复均分。
- 整块工作面板与左侧主对话之间的边界仍使用原有调宽手柄；改变外层宽度不改变内部比例。
- 窗口右上角可以临时放大；`Esc` 返回原布局（焦点在输入框、终端或输入法组合中时，`Esc` 留给它们自己）。`Alt + 数字` 按物理键位匹配，macOS 上同样可用。关闭窗口会把标签移入相邻窗口，不会关闭标签本身。
- 不方便拖动时，在「窗口操作」菜单中选择「移动当前标签」，再点击落点；`Esc` 取消。聚焦标签后，`Alt + Shift + 方向键` 可将该标签拆向相应边缘。

已有单标签窗口可以重新定位，即使当前已达到四窗口上限；从仍有其他标签的窗口再拆出第五个窗口则不产生落点预览。

## 状态与内容

分屏布局按工作区保存在当前渲染进程内，收起面板不会丢失；应用重启不恢复分屏布局。工作区或会话变化导致标签消失时，对应的空窗口会收拢。标签本身的持久化沿用各功能已有机制。

标签内容保持在同一 DOM 父节点下，用稳定标签 ID 作为 React key，移动仅改变矩形位置，不重新挂载聊天、终端或文件预览。文件窗口使用各自的内容读取与滚动状态，共享工作区文件树和版本刷新；浏览器 guest 则继续由独立宿主持有，多个可见窗口可以同时显示各自的网页。网页的登录状态、安全策略和 Browser Use 行为见[浏览器文档](./browser.md)。

## 实现位置

- `apps/desktop/src/renderer/components/workbench-layout.ts` 的 `reconcileWorkbenchLayout`、`dropWorkbenchTab`、`mergeWorkbenchPane`、`workbenchGeometry`：标签组、二叉分隔树、四窗口上限和落点几何。
- `apps/desktop/src/renderer/components/WorkbenchPanel.tsx` 的 `WorkbenchPanel`：内容生命周期、拖拽预览、尺寸与可见窗口。`startTabPointerDrag` 使用指针捕获与移动阈值，不依赖 Chromium/macOS 的原生 HTML 拖拽循环。
- `apps/desktop/src/renderer/components/WorkbenchTabStrip.tsx` 的 `WorkbenchTabStrip`：每窗独立标签栏、键盘操作与窗口菜单。
- `apps/desktop/src/renderer/components/preview/FilePreviewContext.tsx` 的 `FilePreviewScope`：单个文件的独立读取、滚动和跳转。
- `apps/desktop/src/renderer/components/browser/BrowserViewHost.tsx` 的 `BrowserViewHost`：按可见标签集合投影多个 guest。
- `apps/desktop/src/renderer/hooks/useSidebarResize.ts` 的 `useSidebarResize`：继续负责外层面板宽度。

## 验证

```bash
pnpm --filter @vela/desktop test:workbench
pnpm --filter @vela/desktop test:workbench:ui
```

前者覆盖状态模型及已有外层调宽规则；后者在真实 Electron 中用 `sendInputEvent` 的鼠标按下、移动和松开验证标签拖动，而不是派发 `DragEvent`；同时覆盖玻璃顶栏与标签尺寸、落点预览、布局、页面互换、标签栏收回、关闭窗口合并、草稿 DOM 不变、两个文件与两个真实 webview 同时显示，以及内外调宽。`test:workbench:ui` 已登记到统一 UI 套件。
