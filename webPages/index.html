壹 · 名字

為什麼叫 Vela

Vela 是南天的「船帆座」。古希臘人把最大的星空之船 Argo 拆成船底、船尾與船帆，帆，是推動它前行的那一部分。

寫程式像一次不確定終點的航行：風向會變，海圖會錯，總有人在半夜盯著一條紅色的報錯發呆。我們不想造一艘自己開走的無人船，只想做一面帆：把風借給你，舵仍握在你手裡。Harness 則是韁繩，讓力量有方向，也讓你隨時能勒住它。

工具該讓人更像自己，而不是把人替換掉。

貳 · 看見

讓過程退後，
讓事情浮現

好的助手不會一直說話。讀了哪些檔案、改了哪幾行、跑了什麼指令，都該被記下，卻不必擠佔你的視線。

緊湊模式把連續的工具呼叫收成一行行過程線；要細節，點開即是 diff 與輸出；做完了，整輪過程可以收起，只留結論。

參 · 同行

一個人想不完的事，
分給一支小隊

大任務來了，主代理像領隊一樣先拆開：有人查路由，有人修登入，有人挑剔地審邊界。他們各自行走，也互通消息。

點開任一子代理的名字，就能看它想了什麼、做了什麼。探索者只讀、不動檔案；能動手的成員，遵守你為這次對話設下的權限。分工，卻不失控。

肆 · 回溯

信任，
來自可以被檢查

我們不要求你相信 AI，只是把航海日誌還給你。

切到「軌跡」，每次思考、工具呼叫與返回依時間排開；首個 Token 的等待、生成耗時、快取命中、最初的系統提示詞，沒有一樣被藏起來。出了錯，你能順著航跡，回到它第一次偏離的地方。

伍 · 行囊

隨身帶著的東西

航行不只靠一面帆。這些是你出發時，已經替你備好的。

01三種節奏Agent 日常動手；Plan 先寫方案、批准再行動；Goal 為長目標持續推進。
02記憶兩份 Markdown 記住偏好與專案約定，看得見、改得了、清得掉。
03本地工作區直接在你的倉庫，或獨立的 Git worktree 中工作，不必搬家。
04MCP 與整合連接外部工具、按需發現；專案設定須經你確認信任。
05任務配方把反覆做的事寫成範本，填幾個參數就能再來一次。
06定時任務每天、每週或一個 Cron，讓例行的事自己上路。
07Skill一個含 SKILL.md 的資料夾，就教會它一項新手藝。
08模型自選登入提供方，或接上你自己的模型介面。
09淺色 · 深色中英文介面，日與夜都能舒服地工作。
10用量上限為單次任務設下時間與 Token 的上限，接近時提醒，到頂即止。
11交接包把進度、決定與待辦整理成一份，換個對話也能接著走。
12Git 面板變更、歷史與衝突在同一處檢視，逐檔並排審閱、逐塊暫存、逐步提交。
13輸入預測每輪回覆後，把你可能接著要說的話以灰字備好，按 Tab 填入，空白時按 Enter 直接送出。
14面板裡的聊天在工作面板的分頁開啟獨立對話，與檔案、終端機、差異並排進行。
15檢查點由你掌控可關閉檔案檢查點，也能一鍵刪除全部記錄，或只清掉較早的輪次。

陸 · 分寸

關於邊界，我們想誠實

VelaHarness 運行在你的本機，對話、帳號與執行軌跡都存於 ~/.vela，而非某個陌生的伺服器。執行權限分三檔：

  • 每次詢問跑指令前先問你
  • 幫我批准模型判斷風險，有風險才打擾你
  • 完全訪問交付信任

需說明：這是互動式審批策略，並非作業系統級沙箱；遠端與隔離環境目前尚未支援。我們寧願把話說在前頭。

柒 · 啟航

從一行指令開始

macOS（Apple Silicon）可直接下載安裝包：最新版 v1.1.9。也可從原始碼啟動，需要 Node.js 22.19+ 與 pnpm。

git clone https://github.com/KryptonGao/VelaHarness
cd VelaHarness
pnpm install
pnpm dev
  1. 登入模型提供方，或接上自己的模型介面
  2. 選一個本機專案目錄或 Git worktree
  3. 挑一種節奏，說出你想完成的事

以 Pi Agent 為運行時，Electron · React · TypeScript 構建，Apache-2.0 授權。
